# OmniSpatialGraph

OmniSpatialGraph is specified as a standalone, CLI-first temporal graph and GraphRAG engine. It is **not implemented in this repository**; G0 has not started ([purpose](docs/OSG_MVP_SPEC.md:43), [status](docs/OSG_MVP_SPEC.md:926)).

Start with [specification 2.0](docs/OSG_MVP_SPEC.md), [agent guidance](AGENTS.md), and the [maintainer wiki](docs/maintainer-wiki/index.md). The wiki is locally retained and ignored under the current user rules.

There is no application quickstart or build/test toolchain. This documentation-only initialization does not approve implementation or create a knowledge graph. See [workflows](docs/maintainer-wiki/workflows.md) for future gate requirements.
