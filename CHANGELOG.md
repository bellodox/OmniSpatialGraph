### Added

- 2026-10-15: **More languages and Tree-sitter for TypeScript/JavaScript.** C#, C, C++ (`.cpp .cc .cxx .hpp .hh .hxx .h`), Ruby, PHP, Kotlin, Swift and Solidity are indexed (declarations, calls, imports where the language names files or modules), from `@vscode/tree-sitter-wasm` and the new exact dependency `tree-sitter-wasms` 0.1.13. TypeScript and JavaScript (`.ts .tsx .mts .cts .js .jsx .mjs .cjs`) now use Tree-sitter instead of the compiler API, with the compiler's rules kept: same ids, line ranges, signatures, body digests, calls and imports (identical output on 2,312 TS/JS files from this repository and its dependencies; one grammar difference found and handled: a generic call after `await` or `!`). The compiler-based provider and its fallback are removed. Unique-name call fallbacks: `Type.member` repository-wide, and bare names among C/C++ files. `vendor`, `__pycache__`, `.venv`, `venv` and `Pods` directories are skipped. The Swift grammar is compiled baseline-only because its optimizing compile otherwise blocks process exit for about 16 seconds. The data format stays 2; the scan cache version changed, so the first `sync` re-reads every file.
- 2026-10-15: **`osg restore`.** Without options it lists backups (a pure read). `restore --backup <name>` copies the backup aside and verifies it, saves the current store as a `*-pre-restore` backup (unverified if the current store cannot be read), swaps the stores, verifies again, clears the caches, rewrites `.osg/export/episodes.jsonl` and sets the data format recorded in the backup; any failure puts the previous store back. Backups now include `meta.json` (format, head, counts); older backups without it are treated as format 1, so `migrate` follows. New error `BACKUP_NOT_FOUND` (exit 7). `*-pre-restore` backups are never pruned.
- 2026-10-15: **Tree-sitter** parsing (`@vscode/tree-sitter-wasm` 0.3.1, MIT, WebAssembly) replaces the line-based fallback for Python, Go, Rust and Java: qualified declarations, calls (including `self`/`this`/receiver and `Type.member` calls), imports (Python modules, Java imports, Rust `mod`, Go same-package), body digests, and a `PARSE_RECOVERED` warning for files with syntax errors. The line parser remains only as a fallback (`TREE_SITTER_UNAVAILABLE`). TypeScript and JavaScript stay on the compiler API.
- 2026-10-15: **Schema migration.** `.osg/config.json` records a data `format` (absent means 1). New `osg migrate [--dry-run]`; `sync` refuses an older format with `MIGRATION_REQUIRED`, any command refuses a newer one with `UNSUPPORTED_FORMAT`. Format 2 re-indexes Python, Go, Rust and Java under Tree-sitter identities and carries episode links from the old line-parser identities (same file and last name segment, one-to-one only). Migration verifies, takes a `*-pre-migrate` backup that later backups never prune, appends commits, verifies again and then records the format.
