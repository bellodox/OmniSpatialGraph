### Implementation and trust boundaries

- **Parser:** [Tree-sitter WASM](../packages/indexing-kilo/src/treesitter.ts:34) covers TypeScript, JavaScript, Python, Go, Rust, Java, C#, C, C++, Ruby, PHP, Kotlin, Swift and Solidity. Missing grammars warn and fall back to limited line parsing, not equivalent language coverage. This is not formal Approach A acceptance or third-party adaptation approval.
- **Swift:** [a subprocess](../packages/indexing-kilo/src/treesitter.ts:675) selects baseline-only V8 compilation at startup, passes source on stdin without a shell, and limits execution to 60 seconds/output to 16 MiB. It avoids an observed fatal in-process Node 24 V8 compilation failure. Failure-preservation and startup cost remain [follow-ups](maintainer-wiki/open-work.md#separately-authorized-follow-ups).
- **Recall:** [weighted lexical ranking](../packages/core/src/retrieval.ts:69), limited typed two-hop expansion and episode reservation return evidence, not semantic/vector search, exhaustive knowledge or a generated answer. Entity queries prioritize the entity and related episodes; budget pressure can omit relevant items. Whole-envelope token counts are estimates, not tokenizer guarantees.
- **Memory:** [ingestion](../packages/core/src/memory.ts:143) and [retrieval](../packages/core/src/retrieval.ts:175) independently restrict supersession to current live hypothesis episodes. Protected, retracted, malformed, self, absent and non-episode references cannot demote records. Relations identify immediate successors, not a transitive canonical truth. Supersession never erases history or promotes status.
- **Authority:** [state](../packages/core/src/state.ts:36) is reconstructed from committed rows/reachability; permitted files are reparsed rather than trusting editable scan-cache results. [Doctor](../packages/cli/src/index.ts:625) compares full authoritative rows, head and unique IDs: malformed cache is unavailable; well-formed stale/forged cache is a mismatch. Removed trusted fast paths are a deliberate safety-first tradeoff, not measured optimization.
- **Source privacy:** shared [current-source policy](../packages/indexing-kilo/src/index.ts:63) applies mandatory exclusions, supported-file rules, ancestor ignores and static path/link checks before hashing/snippet reads, including old-commit context. Historical metadata never authorizes current content. Denied/unverifiable access yields stale citations/no snippet; optional [snippets](../packages/core/src/retrieval.ts:51) are explicitly untrusted string-value wrappers. Windows exclusions case-fold before traversal/ignore/content reads, without changing ID/hash case semantics.
- **History and writes:** append-only element/commit rows, atomic head CAS and pure CLI reads remain the model. [Four total attempts](../packages/core/src/memory.ts:10) use 50–250 ms jitter; success for every concurrent writer is not guaranteed. [Storage reads](../packages/storage-lance/src/index.ts:90) return defensive copies on hits/misses, including nested extents.
- **Public boundary:** the [worker launcher](../packages/cli/src/public.ts:57) captures native stdout/stderr, validates one IPC result and preserves coded exits/recovery metadata. Direct APIs/internal backend and hostile Node configuration before launcher startup do not inherit that guarantee. Its IPC limit is post-deserialization, not a universal hostile-worker memory bound. Redact local diagnostics before sharing.

Init staging cleanup is normal-unwinding coverage; table-directory rename/config hard-link publication is not proved fsync/power-loss durability. Current-source/cache checks add unbenchmarked work.
