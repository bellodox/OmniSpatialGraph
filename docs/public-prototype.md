### Implementation and trust boundaries

- **Parser:** [Tree-sitter WASM](../packages/indexing-kilo/src/treesitter.ts:34) covers TypeScript, JavaScript, Python, Go, Rust, Java, C#, C, C++, Ruby, PHP, Kotlin, Swift and Solidity. Missing grammars warn and fall back to limited line parsing, not equivalent language coverage. This is not formal Approach A acceptance or third-party adaptation approval.
- **Swift:** [one persistent child per scan](../packages/indexing-kilo/src/treesitter.ts:680) uses baseline-only V8 compilation and newline-delimited JSON without a shell. Named 16 MiB request/response caps, strict UTF-8/shape validation and a 60-second per-request timeout terminate failed helpers; [extraction failure aborts before commit](../packages/indexing-kilo/src/index.ts:178), preserving indexed facts/links instead of treating failure as deletion. This isolates the observed fatal Node 24 V8 compilation failure, not a whole-scan or real-repository performance guarantee.
- **Recall:** [weighted lexical ranking](../packages/core/src/retrieval.ts:75) remains default; [optional semantic vectors](../packages/core/src/retrieval.ts:152) blend into task seeds before typed expansion and episode reservation. Entity queries are unchanged; budget pressure can omit items. The [adapter](../packages/cli/src/embedder.ts:19) allows downloads only for explicit embedding; reads use local models with lexical fallback. [Format-2 cache validation](../packages/core/src/embedding.ts:193) binds metadata/bytes and rejects invalid/mixed/duplicate/nonunit data; defensive cosine is bounded. Header-last publication may temporarily fall back. A digest is not authentication. Whole-envelope token counts are estimates, not tokenizer guarantees; the controlled model result below is not human risk approval.
- **Memory:** [ingestion](../packages/core/src/memory.ts:143) and [retrieval](../packages/core/src/retrieval.ts:202) independently restrict supersession to current live hypothesis episodes. Protected, retracted, malformed, self, absent and non-episode references cannot demote records. Relations identify immediate successors, not a transitive canonical truth. Supersession never erases history or promotes status.
- **Authority:** [state](../packages/core/src/state.ts:36) is reconstructed from committed rows/reachability; permitted files are reparsed rather than trusting editable scan-cache results. [Doctor](../packages/cli/src/index.ts:680) treats malformed cache as unavailable and ignores a well-formed cache naming another head; a cache claiming the current head must match full authoritative rows, count and unique IDs. Removed trusted fast paths are a deliberate safety-first tradeoff, not measured optimization. Vector caches do not alter graph hashes, verification or backup authority.
- **Source privacy:** shared [current-source policy](../packages/indexing-kilo/src/index.ts:63) applies mandatory exclusions, supported-file rules, ancestor ignores and static path/link checks before hashing/snippet reads, including old-commit context. Historical metadata never authorizes current content. Denied/unverifiable access yields stale citations/no snippet; optional [snippets](../packages/core/src/retrieval.ts:52) are explicitly untrusted string-value wrappers. Windows exclusions case-fold before traversal/ignore/content reads, without changing ID/hash case semantics.
- **History and writes:** append-only element/commit rows, atomic head CAS and pure CLI reads remain the model. [Four total attempts](../packages/core/src/memory.ts:10) use 50–250 ms jitter; success for every concurrent writer is not guaranteed. [Storage reads](../packages/storage-lance/src/index.ts:90) return defensive copies on hits/misses, including nested extents.
- **Public boundary:** the [worker launcher](../packages/cli/src/public.ts:57) captures native stdout/stderr, validates one IPC result and preserves coded exits/recovery metadata. Direct APIs/internal backend and hostile Node configuration before launcher startup do not inherit that guarantee. Its IPC limit is post-deserialization, not a universal hostile-worker memory bound. Redact local diagnostics before sharing.
- **Swift public error contract:** [backend](../packages/cli/src/index.ts:24) and [public launcher](../packages/cli/src/public.ts:8) explicitly map `SWIFT_PARSE_FAILED` to exit **1**, category **internal**, with the [static path-free message](../packages/cli/src/index.ts:56) “Swift extraction failed; scan aborted before committing”. The [public regression](../tests/swift.test.mjs:165) exercises actual malformed helper output and a crashing child, preserving head/rows/episode links and checking real-child cleanup.
